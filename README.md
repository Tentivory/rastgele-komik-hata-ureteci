# Rastgele Komik Hata Üreteci 😭😅

## Bu Ne Lan?

Bu repository, insanlığın en büyük sorunlarından birini çözmek için yaratılmıştır: **Sıkıcı, anlamsız ve ruhsuz hata mesajları.**

Artık hata aldığınızda ağlamayacaksınız. Güleceksiniz. Veya ikisini birden yapacaksınız. Biz karışmıyoruz.

### Özellikler (Abartılı)

- **%100 Çalışır**: Gerçekten Python çalıştırın, hata üretir. İnanmazsanız deneyin.
- **Sonsuz Yaratıcılık**: Aslında sonlu, ama listesi uzun. Genişletmek serbest.
- **Dramatik Efekt**: Her hata arasında 0.5 saniye bekler. Çünkü hayat hızlı, hatalar yavaş olmalı.
- **Hiçbir İşe Yaramaz**: Tamamen gereksiz. Ama eğlenceli. İşte bu yüzden var.

### Nasıl Kullanılır?

```bash
python hata_ureteci.py
```

Sonra kaç tane istediğinizi söyleyin. Veya Enter'a basın, 5 tane versin.
